
# Firelock Companion

“Federal command, however well trained or experienced, has always been second to the Rygoles. Their shared minds move faster than bullets. Food, fuel, ammo, spare parts—no metal soldier has to wonder when their next supply drop is.

If either of its self-destruct modules had functioned, they could have stopped us from ever closing the gap. But fate has an odd humor.

Some scouts found one of those tentacled metal bastards hidden in the forest after a battle. An engineering team ripped it from the ground and brought it home. Its eyes watched them the whole time, but they were smart enough to clip the antennas before loading it up.

When we hooked it up, it seemed curious, but didn’t even hesitate when we fed a fabricated combat scenario. Pulled nearby assets, charted a path for the cargo trucks, distributed infantry between carriers. Planned everything except when to pull the trigger. It’s no Rygonet, but through time and trial, we will finally level the playing field.”

\- Rayleigh Irving, Federal Intelligence

## Installation

Firelock Companion is built and compiled into a single, easy to use .exe file (which you can trust blindly).

To download, simply navigate to the Releases menu (to the right of the files above), extract the compressed file, then run the exe using your choice of a double click or right click > run. Note that Firelock Companion only supports Windows (for now).

It is likely that Windows will try to protect you. Tell it you'd rather trust a stranger on the internet but pressing `More Info`, then clicking `Run Anyway`. I swear it's not a virus, I'm just not paying $100 a month to get verified.

You are free to build the app yourself, but I honestly just use Visual Studio 2022 to build it for me, so start there.

## Feature Requests / Reporting

See something you'd like change? Don't see it because it's handled by code and you can't read the gibberish I've written? Just go to issues and open a new issue with the correct label. 

If you'd like something to be added, please open a new issue with the `enhancement` label! I will never be mad a request, so don't afraid. No promises I'll actually work on it though.
